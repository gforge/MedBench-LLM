## Uppgift
Förfina detta utkast till utskrivningsanteckning genom att åtgärda den specifika kritiken som tillhandahålls. Använd de ursprungliga kliniska anteckningarna som referens.

## Nuvarande utkast
```
{draft}
```

## Kritik att åtgärda
```
{critique}
```

## Ursprungliga kliniska anteckningar (för referens)
```
{notes}
```

## Instruktioner
1. Åtgärda varje problem som identifierats i kritiken
2. Verifiera alla fakta mot de kliniska anteckningarna
3. Lägg till saknad information om den finns i anteckningarna
4. Ta bort redundanser och förbättra tydlighet
5. Behåll det obligatoriska formatet och strukturen

## Output
Tillhandahåll den förfinade utskrivningsanteckningen i samma format som ursprungligt utkast, med alla kritikproblem åtgärdade.
