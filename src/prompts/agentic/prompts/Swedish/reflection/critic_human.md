Utvärdera detta utkast till utskrivningsanteckning mot de ursprungliga kliniska anteckningarna. Identifiera specifika problem som behöver korrigeras.

```
{draft}
```

## Ursprungliga kliniska anteckningar

```
{notes}
```

## Instruktioner
1. Jämför utkastet noggrant mot de kliniska anteckningarna
2. Identifiera faktafel, saknad information, redundanser och koherensproblem
3. Ge specifik, handlingskraftig feedback för förfining
4. Avgör om utkastet är ACCEPTABELT eller BEHÖVER REVIDERING

Balansera klinisk noggrannhet med läsbarhet. En bra sammanfattning fångar kärnan i vårdtillfället - detaljerna finns tillgängliga i daganteckningarna för den som behöver dem.
